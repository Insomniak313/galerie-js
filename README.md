# Galerie JS

Matériel pratique pour un cours **débutant** sur **JavaScript** et **jQuery**, autour d’une galerie d’images. Chaque étape correspond à une branche Git (`tp1`, `tp2`, …).

## Utilisation

1. Choisir la branche du TP : `git checkout tp1` (puis `tp2`, `tp3`, `tp4` selon la séance).
2. Ouvrir `index.html` dans un navigateur (double-clic ou serveur HTTP local).
3. Pour le débogage : outils développeur (**F12**), onglets **Console** et **Réseau**.

Les chemins des fichiers (images, CSS) sont relatifs à la page ouverte : ouvrir la racine du dépôt ou le sous-dossier indiqué pour chaque TP.

## Parcours des TP

| Branche | Contenu principal |
|--------|-------------------|
| **tp1** | Premiers pas : page HTML, script externe, message dans la **console**, vérification du chargement de `main.js` (onglet Réseau). |
| **tp2** | **Fonctions** sur un tableau d’images (catalogue) : filtrage par catégorie, sélection en mémoire. Pas encore de manipulation du DOM : résultats visibles dans la console. |
| **tp3** | **DOM** en JavaScript natif : carrousel (précédent / suivant, pastilles, filtre), `style.css` et dossier `assets/` pour les images. |
| **tp4** | Même carrousel avec **jQuery** (dossier `tp4/`, librairie chargée en CDN — connexion Internet requise pour charger jQuery). |
